# Jarak icon

Jarak (자락, the hem of a cloth): a light page with its top-right corner folded over, three lines
of text and the caret in the design system's purple accent. Same 40-unit tile as Subak's
(`assets/subak/subak.svg`: `#1C1B24`, radius 9.5, a 1-unit `#26252F` edge), one flat glyph,
readable from 16 px ([ADR 0102](../../docs/adr/0102-jarak-fourth-kim-tool.md)).

| File | Use |
| --- | --- |
| `jarak.ico` | Windows, 16–256 px (9 sizes), PNG entries; linked into `jarak.exe` and `jarak-gui.exe` by `crates/kim-winres` |
| `jarak-{16,20,24,32,48,64,128,256}.png` | PNG sizes (Kim Manager's launcher uses the 256 px one) |

Generated by `assets/brand/make_tool_icons.py` (developer tool, needs Pillow; not part of any
shipped binary), never by hand:

```sh
python -I assets/brand/make_tool_icons.py
```
